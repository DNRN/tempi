# tempi

An AI harness built on the pi agent for interactively co-creating playable games. Read [PROJECT.md](PROJECT.md) before planning or building a feature: purpose, users, scope, constraints, and open decisions live there. Update it when they change.

## Conventions

- Tests ship alongside every change; CI runs on push from the start.
- Architecture decisions are recorded in [docs/adr/](docs/adr/). Accepted ones hold: read the one that applies before changing what it decides, and change a decision by superseding it with a new ADR, never by editing it.

## Feature planning

- Tracker: GitHub issues, via `gh` (`origin` → `github.com:DNRN/tempi`)
